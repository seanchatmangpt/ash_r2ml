# Legacy path: graph traversal

AshR2RML does not add a graph-native traversal expression to Ash queries.

Ash relationships remain application/query structure; SPARQL graph-pattern evaluation belongs to the selected OBDA engine operating over generated R2RML.

See [Query surfaces](query-surfaces.md), [Relationships](relationships.md), and [OBDA and virtual RDF](obda.md).

Variable-length path semantics, property paths, and SPARQL algebra are not implemented inside AshR2RML.
